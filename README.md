# AgriLink 农链前端

农业产业链数据大屏的 React 工程基础。事实层和关联层共用一个 Dashboard 和一个 deck.gl 地图实例。当前版本不是原型全部业务功能的复刻。

## 启动

推荐 Node.js 24（`.nvmrc`），使用 npm 与已提交的 `package-lock.json`。

```bash
npm ci
npm run dev
```

打开终端打印的本地地址。`npm run build` 生成 `dist/`，`npm run preview` 预览生产构建。不要直接双击 HTML。

## 已接入

- React 19、TypeScript 严格模式、Vite 8。
- deck.gl 9.4 与静态 GeoJSON：全球、中国、省区聚焦，地图缩放和平移，模式切换保留相机。
- Ant Design 6、Less：暗亮主题、日期区间、左右浮层、详情弹窗和空状态。
- Axios：统一实例、超时、错误归一化、AbortSignal；TanStack Query：查询键、缓存和取消。
- Zustand：模式、区域、时间、选择对象和面板；相机高频状态仅在地图组件内更新。
- dayjs：上海时区日期范围转换；ahooks：容器尺寸观察。
- ECharts：按需注册与懒加载趋势图。
- Oxlint、Vitest；`npm run check` 执行类型检查、Lint、测试和构建。

MapLibre、Tailwind、Turf、HeatmapLayer 暂不引入。地图使用 deck.gl 标准图层，不手写 Canvas 绘制。

## 页面浮层

事实层按 [事实层 PRD（文件内 V1.2）](https://github.com/UpStarData/Project_Design/blob/main/🌾农产品交易大模型/需求/【PRD】AgriLink_事实层V1.0.md) 整理固定页面结构：顶部导航、左右上角面板开关、地图背景、右侧事实卡片区、底部可收展的事实处理日志。区域和时间筛选位于左侧品种选择下方，默认全球和近 1 月；选择区域只更新事实数据，不移动地图视角。

左侧包含数据概览（当前事实、今日新增）、七大领域的三级分类、品种与区域时间筛选、叠加图层及地图快捷控制按钮配置；地图右下角包含搜索与操作按钮。右侧事实卡片在常规屏幕上双列排列，点击卡片会在列表左侧打开毛玻璃详情面板。推演层只预留禁用入口。

事实列表与地图星点来自同一批事实结果。分类、品种、区域、时间、视频类型和快捷搜索共同作用于这批结果；叠加数据图层开关只控制对应地图图层。事实形成过程在详情中直接展开。日志没有实际记录时保留空状态。

## 当前数据状态

当前 Dashboard 会调用事实分类、数量、列表和详情接口。开发时通过 Vite 代理访问 `/api/v1`；生产环境需要配置对应反向代理。

后续接入需要对齐 PRD 的事实字段和日志契约，重新连接查询与筛选。当前分类路径 ID 仅用于页面选择，不作为已确认的后端字段。生产环境的 `/api` 代理由部署服务配置，前端 `VITE_*` 变量公开可读，不填写密钥。

边界来自原型 `agri-llm-demo/data`，已规范为 GeoJSON；来源哈希和精度限制记录在 `public/boundaries/manifest.json`。`npm run import:boundaries -- /源数据目录` 可重复转换。正式上线前需核对边界数据的坐标基准、来源许可和完整性。
