# 地图代码阅读指南

2026-10-09 更新。地图 UI 集中在 `src/components/map/`，不增加新的地图封装框架。

## 阅读顺序

1. `src/components/map/MapCanvas.tsx`：页面入口。管理 2D / 3D / 图谱切换、容器尺寸、原生 deck.gl 控制器和操作按钮。
2. `src/hooks/useMapCamera.ts`：事实/关联各自的相机状态、区域定位、平面滚轮锚点缩放、球体空闲自转。
3. `src/hooks/useMapLayers.ts`：按更新频率缓存图层，管理装饰动画和 SSE 高亮过期。图谱模式暂停地图动画。
4. `src/utils/relationLayers.ts`：大圆路径预计算、地域与屏幕可见性、关系与本体样式、方向箭头和流动光点。
5. `src/utils/mapLayers.ts`：地理边界、事实点、叠加数据、单独更新的影响圆。
6. `src/utils/map.ts`：边界定位与缩放范围计算；`GlobeBackdrop.tsx` / `StarField.tsx` 仅负责视觉背景。

## 球体交互

2D 与球体使用不同的 View ID，且显式指定 GlobeController，避免投影切换后复用旧控制器。事实层和关联层共用 GlobeView 的原生 GlobeController，支持拖动、触控与滚轮。设置 `inertia: 300`、`scrollZoom: { smooth: true }`，缩放围绕中心进行。不要在 `onViewStateChange` 中删除控制器返回的 transition 字段，否则会截断惯性。

GlobeController 9.4 会按纬度修正缩放约束，因此相机的 minZoom/maxZoom 使用赤道基准；按钮使用当前位置的纬度修正值。球体保持完整可见，不在放大极限强制切换到平面；通过 2D 按钮或点击地域进入平面地图。平面缩小到世界概览后仍可回到球体。

拖动、缩放和惯性过程中暂停自动旋转，停止交互 1.5 秒后恢复。相机高频状态留在地图 hooks 中，不写入 Zustand。

## 性能边界

- `prepareRelationPaths` 只随实体、关系、球体/平面投影变化计算，避免每次拖动重新生成 33 个大圆采样点。
- `createRelationLayers` 随相机更新可见性和屏幕箭头；`dataComparator` 在可见关系、路径和样式相同时保留 PathLayer 的 GPU 缓冲。
- 光点动画与事实影响圆独立于底图。流动不会重建行政边界或关系路径。
- `Dashboard` 缓存筛选后的地图数据，开关抽屉不会重新生成全部路径。
- 屏幕关系可见性与箭头仍有 CPU 计算；未承诺固定帧率，实际性能与设备及数据规模有关。

## SSE 与右侧详情

`api/processingLogs.ts` 统一 EventSource 生命周期与消息接收，路径按 mode 选择；`hooks/useProcessingLogs.ts` 保存每层最近 200 条日志并处理关联高亮；`ProcessingLog.tsx` 只负责显示和滚动。共用接收器支持文本及非结构化 JSON。关联 SSE 尚未开发，当前不建立关联连接；后端就绪后修改 `useProcessingLogs.ts` 的 `enabledByMode` 即可启用。切层或卸载时关闭旧连接，收起日志不停止接收。

两层日志默认收起，隐藏“实时”状态文字；保留故障状态和暂停自动滚动按钮。两层详情共用 `DetailDrawer`。布局以 `.right-panel-open` 为依据，列表收起后详情靠右，不清空详情栈。证据列表允许字段缺失或为 null。
