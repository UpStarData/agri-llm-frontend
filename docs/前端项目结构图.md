# 前端项目结构图

2026-10-09 按实际代码更新。继续沿用现有 components、pages/Dashboard/component、hooks、api、utils；共用容器与业务内容分开，不新增独立路由。

```text
src/
├── api/
│   ├── request.ts                  # Axios 唯一实例与统一错误处理
│   ├── fact.ts                     # 已接入事实接口
│   ├── relation.ts                 # 关联图谱/本体/关系接口
│   ├── processingLogs.ts           # 两层共用 SSE，按 mode 选择路径
│   └── dashboard.ts                # 静态边界加载
├── components/
│   ├── DashboardHeader.tsx         # 模式和主题
│   ├── map/
│   │   ├── MapCanvas.tsx           # 地图入口、视图/控制器与容器
│   │   ├── MapControls.tsx         # 共用地图操作
│   │   ├── FactMapTools.tsx
│   │   ├── RelationMapTools.tsx
│   │   ├── RelationGraphCanvas.tsx # ECharts 关系图谱
│   │   ├── GlobeBackdrop.tsx       # 球体海洋背景
│   │   └── StarField.tsx
│   ├── LeftLayerDrawer.tsx         # 左侧容器入口
│   ├── RightRecordsDrawer.tsx      # 事实卡片业务
│   ├── DetailDrawer.tsx            # 共用详情外壳和返回按钮
│   ├── FactMenu.tsx                # 事实分类与筛选
│   ├── FilterBar.tsx               # 事实地域/时间
│   └── MapControlSettings.tsx
├── pages/Dashboard/
│   ├── index.tsx                   # 两层查询和组件编排
│   ├── index.less                  # 既有四区布局、共用样式
│   └── component/
│       ├── LayerDrawer.tsx         # 左右浮层、滚动位置恢复
│       ├── VarietySelect.tsx       # 共用品种选择与显示名称
│       ├── RelationMenu.tsx
│       ├── EntityList.tsx          # 独立本体分页卡片
│       ├── FactDetail.tsx
│       ├── EntityDetail.tsx
│       ├── RelationDetail.tsx
│       ├── EvidenceFacts.tsx       # 支撑事实回溯
│       ├── RelationContextBar.tsx
│       └── ProcessingLog.tsx       # 日志显示与暂停滚动
├── hooks/
│   ├── useFactQueries.ts
│   ├── useRelationQueries.ts       # 图谱/列表/概览/详情独立查询
│   ├── useMapCamera.ts             # 分层相机、缩放、平面/地球交互
│   ├── useMapLayers.ts             # 分频缓存、地图动画与高亮过期
│   ├── useProcessingLogs.ts        # 分层日志缓存、订阅生命周期
│   └── useBoundaries.ts
├── utils/
│   ├── map.ts                      # 既有边界与相机计算
│   ├── mapLayers.ts                # 边界/事实/叠加图层
│   ├── relationLayers.ts           # 本体/关系/方向与流动
│   ├── relationFilters.ts          # 两级分类/14种关系/品种筛选
│   ├── mapTooltip.ts
│   ├── factFilters.ts
│   └── theme.ts                    # 本地主题保存和恢复
├── types/index.ts
├── store.ts                        # 交互状态；不复制查询数据
├── queryClient.ts
├── App.tsx
└── main.tsx
```

public/boundaries 保留原型来源的世界/中国 GeoJSON 和 manifest；scripts/import-boundaries.mjs 保留可复现导入方式。tests 覆盖既有事实接口和地图逻辑，以及关联筛选、显隐、分层恢复和详情返回。

旧的 AI/分析/趋势面板、未使用的地图操作入口、静态分类表、旧地图/统计查询 hooks 及测试装饰粒子已删除。图谱仍使用 ECharts，地图使用 deck.gl。

阅读地图实现请从 [地图代码阅读指南](./地图代码阅读指南.md) 开始。
