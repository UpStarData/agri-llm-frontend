## 页面与数据关系

```mermaid
flowchart TD
  Dashboard --> Header[模式切换 / 地理筛选]
  Header --> Store[Zustand 交互状态]
  Dashboard --> MapCanvas[单一 MapCanvas]
  MapCanvas --> Layers[deck.gl 数据图层]
  GeoJSON[静态 GeoJSON] --> Layers
  Store --> Query[TanStack Query]
  Query --> Axios[Axios / 后端接口]
  Query --> Layers
  Query --> Panels[概览 / 详情 / 图表]
  Store --> Panels
```

后续较复杂组件的样式可在 `components/` 下增加同名 `.module.less` 文件，仍保持平铺。暂不引入 `features/`、全局路由和每组件一个目录；出现独立页面需求后再扩展。
