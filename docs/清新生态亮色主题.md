# 清新生态亮色主题

本次直接修改 Agrilink 原项目。deck.gl 的依赖及安装版本为 9.4.0（core/layers/react/widgets），没有变更依赖。

## 实际底图与范围

2D 使用 MapView + WebMercatorViewport，3D 使用 deck.gl 的实验性 GlobeView/GlobeViewport。底图为 `public/boundaries` 的 GeoJSON 世界/中国行政边界。海洋是地图容器背景与 GlobeBackdrop 中跟随投影尺寸的 CSS 球面渐变，并非 Mapbox、Cesium 或 Three.js 材质。

保留原页面布局、面板尺寸、列表/新闻/视频结构、图层顺序与 ID、请求参数、数据来源、路径计算、相机/控制器、拾取和点击回调。暗色沿用原色值。亮色切换通过现有 Zustand colorTheme 状态更新。

当前没有道路、独立海岸线或行政区文字标签数据。本次不添加底图提供商或业务图层；国界和海岸仍共用 GeoJSON 多边形轮廓的浅蓝描边。coastline Token 预留给未来独立海岸线数据，不声称已经实现独立海岸着色。现有港口/来源文字、比例尺与悬浮提示已采用亮色主题。3D 光照感延续原 CSS 海洋渐变与轻微阴影；没有新增真实球面光源或陆地材质光照。

## 统一 Token

`src/utils/ecologyTheme.ts` 中的 `ECOLOGY_THEME` 为唯一亮色色值配置。App 将字符串 Token 映射成 `--eco-<key>` CSS 变量；Ant Design、deck.gl 和 ECharts 直接引用相同 Token，并使用 rgb/rgba 转换。

| Token | 值 | 用途 |
| --- | --- | --- |
| page | #F4F8FB | 页面、地球外部背景、图谱背景 |
| panel | #F4F8FB | 面板、控件、详情、搜索、提示 |
| card | #F9FBFD | 新闻/视频/本体/证据卡片 |
| text | #1F2937 | 标题、关键指标、标签 |
| muted | #6B7C93 | 摘要、来源、时间、次级文字 |
| ocean | #7EC8E8 | 2D 海洋、3D 海洋渐变基色 |
| land | #E6F1D8 | 陆地主色 |
| borderCountry | #BFD8E6 | GeoJSON 边界轮廓 |
| coastline | #8EC7E0 | 独立海岸线预留，当前共用行政边界轮廓 |
| selected | #7FDCB0 | 半透明选区、选中节点描边、卡片边框 |
| route | #3FB2E7 | 一般非生产类节点；关系颜色改为共用左侧关系分类图例 |
| priorityRoute | #F7A84D | 影响圈、市场节点；关系高亮保留分类色 |
| production | #28B463 | 生产节点与事实点 |
| hub | #008BD9 | 港口/机场枢纽、交互、今日新增指标 |
| anomaly | #FF6B6B | 风险节点与错误状态 |
| border | #E5EAF2 | 面板/卡片/控件轻量边框 |

辅助 Token：landPalette 为低饱和浅绿/米色分区色；oceanLight/oceanShade 用于自然球面渐变；关系分类色共用 relationDomainInfo 配置；panelGlass 为保留现有面板基色的 85% 透明背景，左右面板和详情配合 blur(10px) 实现毛玻璃；shadow 为低强度阴影；selectedSurface 为半透明选中卡片背景；warningText/anomalyText 使用更深的橙红色保证小字号日志文字可读性。

## 受影响图层

| 现有图层 ID | 亮色表现 |
| --- | --- |
| world-boundaries / china-boundaries | 浅绿/米色陆地、轻量浅蓝轮廓，选区 alpha 170，悬停 alpha 90 |
| real-facts | 绿色适中事实点，选中时才出现额外描边 |
| overlay-ports | 蓝色中心点与浅色圆环 |
| overlay-port-labels / overlay-source-labels | 深色易读文字 |
| overlay-fact-sources | 绿色来源点 |
| fact-geo-points | 产区绿色、港口/机场蓝色圆环、市场橙色、风险红色 |
| overlay-influence-ring-0..3 | 半透明橙色影响圈，原动画与地理半径不变 |
| real-relations | 关系轨迹使用 relationDomainInfo 分类色（与左侧关系筛选共用 relationColor），普通 alpha 165，重点 alpha 230，无关线 alpha 40；重点不改变分类色 |
| relation-arrows / relation-flow | 跟随对应关系线颜色与透明度 |
| real-entities | 使用接口 displayGroup 识别产区、市场、港口/机场、风险；普通节点适中、枢纽圆环、选中节点额外描边 |

ECharts 图谱关系线同样共用左侧关系分类色和绿/蓝/橙/红分类节点，文字和提示背景统一。原图谱没有网格线，无需新增或修改网格结构。

`useMapLayers` 的 memo 依赖包含 colorTheme。关键颜色、节点半径、描边、选中事实 ID、动画颜色和位置 accessor 配置 updateTriggers；节点 dataComparator 即使复用数据，也不会阻止主题/选中状态刷新 GPU 属性。边 dataComparator 比较路径、宽度和颜色，主题切换会使颜色变化生效。关系流动点沿用原路径与颜色。

## 验证

`npm run check` 通过 TypeScript、oxlint、12 个测试文件（78 个测试）以及 Vite 生产构建。构建仍提示既有大体积 chunk，未进行与本次配色无关的拆包。

本地浏览器检查亮色事实 2D、关联 3D/2D、亮暗切换和 ECharts 图谱；确认背景色计算结果为 rgb(126, 200, 232)，3D/2D/图谱按钮的 aria-pressed 状态正确，浏览器无 error 日志。既有交互测试继续验证地理定位、跨区域路径、相机、筛选、关系拾取和详情返回；新增测试验证同一数据主题切换的 updateTriggers 和分类映射。

手动复查可运行 `npm run dev`：切换亮色后打开事实层与关联层；切换 2D/3D、缩放/拖动、点击国家/省份/事实/节点/轨迹、打开详情、启用港口/机场/市场/风险/影响圈，检查低透明度选区不会挡住其他业务数据；再切回暗色确认恢复原表现。

后续修正：关系轨迹、箭头、流动点、图谱和左侧筛选统一调用 relationColor；生产供应绿色及其余分类色保持图例语义。左右面板与本体/事实/关系详情的计算样式验证为背景 alpha 0.85 和 backdrop-filter: blur(10px)。
