# 关联层 V1.3 实现方案与已确认边界

需求基线：[关联层 PRD V1.3](https://github.com/UpStarData/Project_Design/blob/main/🌾农产品交易大模型/需求/【PRD】AgriLink_关联层V1.3.md)。讨论确认日期：2026-10-08。原型参考：[v1.0.5](https://upstardata.github.io/agri-llm-demo/v1.0.5/)。原型中残留的九类对象、指标本体、旧关系类型和演示裁剪不能替代 PRD。

本文记录本轮产品决策和前端实现边界。涉及关联接口的内容是**参照事实接口返回的契约草案**，不是已上线接口。用户已确认关联后端尚未实现；姊妹项目 `../DataCenter-Back` 未提供对应实现。请求路径、字段和 SSE 消息须与后端确认后启用，不在前端调用模型、抽取本体、身份归一或推断关系。

## 1. 本期范围

- 一个 Dashboard、事实层与关联层两个业务模式，共用四区布局和地图实例。
- 关联层先完成 3D 地球、2D 地图、本体分类与品种筛选、关系筛选、跨区域控制、本体卡片与详情、关系详情、支撑事实回溯、上下文入口、处理日志承载。
- 本体列表独立查询和分页；首次进入、筛选变化和分页操作触发请求。**不做 30 秒轮询**。
- 左侧样式沿用事实层的 menu-section、Collapse、分类按钮、全选/反选、数据概览和 Switch。
- 图谱视图本期只提供技术方案；不增加可点击的未实现入口。推演层不开发。
- 主题保存到 localStorage；无记录或记录无效时默认暗色；存储不可用时仍允许会话内切换。
- 不加入演示节点、虚构坐标、前端推理、自动社区摘要、时间轴等额外功能。

## 2. 已确认的歧义处理

1. 图谱缩放只改变比例；展示当前加载图谱中符合筛选的全部本体和关系，不按缩放级别隐藏。这里的“全部”不是一次加载整个数据库。
2. 关系字典以 4.3.7 的 14 种约束表为准：生产、供应、采购、运营、入驻、合作、位于、运输至、储存于、发布、适用于、监管、影响、发生于。颜色按六个关系域分组。合作无方向，其他类型有方向。
3. 本体筛选采用四个一级类、17 个二级类；八类卡片只是摘要模板的归组方式，不作为另一套身份类型。地缘风险区等模板缺口单独记录；新增风险模板字段为待确认配置，仅显示接口实际提供的值。
4. 分类、品种筛选始终优先。关系两端都通过这些筛选后，跨区域开关才允许展示一端在当前视角内、另一端在外的关系；不能通过跨区域开关复活已筛掉的本体。
5. 上下文重点本体可越过地理层级与跨区域开关，但仍遵守分类、品种筛选和坐标要求。缺少坐标不能在地图上定位。

## 3. 组件和布局边界

```text
Dashboard
├─ DashboardHeader
├─ MapCanvas（稳定挂载）
│  ├─ 边界与底图
│  ├─ 事实图层
│  └─ 本体 / 关系图层
├─ LeftLayerDrawer / LayerDrawer
│  └─ FactMenu 或 RelationMenu
├─ RightRecordsDrawer 或 EntityList / LayerDrawer
├─ DetailDrawer
│  └─ FactDetail / EntityDetail / RelationDetail / EvidenceFacts
├─ RelationContextBar
└─ ProcessingLog
```

共用容器承担显隐、位置、滚动、标题和详情返回。业务组件承担查询、字段和交互。业务内容不依赖左右位置，后续可调整布局。保留既有目录结构，不引入新的路由或大型通用 schema 渲染系统。

MapCanvas 始终处在同一组件位置且不设置 mode key，不重建 WebGL。相机交互抽到 `useMapCamera`；球体/平面状态、相机、地域层级按 mode 保存。事实地图行为沿用现有实现；关联层默认地球，可切平面、拖动、缩放和复位。平面支持东西向循环，纬度有界。关联地球放大进入平面，平面缩小至全球阈值进入地球；当前采用既有缩放步长与全球适配算法，球体缩放至适配上限切换平面；球面视觉细节留待真实数据联调确认。

## 4. 状态归属

| 状态 | 归属 | 切换规则 |
| --- | --- | --- |
| mode、主题 | 页面共享 | 主题写入本地；mode 仅当前会话 |
| 品种 | 跨层共享，现有 factFilters.varieties 为唯一存储 | 任一层修改另一层同步；上下文按品种重建 |
| 日期、国家/省份、事实分类、事实搜索和视频 | 事实层 | 不传入关联请求 |
| 本体分类、关系类型、关联搜索、跨区域开关 | 关联层 | 不覆盖事实筛选 |
| 地图相机、地理层级、球体/平面、快捷控制、抽屉和列表位置 | 分层记忆 | 切换恢复原状态 |
| 选中对象、详情栈、一级邻居高亮 | 分层记忆 | 类型和 ID 一起保存，防止 ID 碰撞 |
| 关联事实/起点上下文、构建版本 | 关联层 | 缩放、分类筛选、切换视图不重建 |
| 请求数据 | TanStack Query | 不复制到 Zustand |

详情栈支持“本体 → 关系 → 支撑事实”；后退返回上一个详情，支撑事实不切 tab、不移动地图。事实详情查询不再限定 fact mode。

现有事实接口只接受单个 commodityId；关联品种支持多选 commodityIds。事实层仍沿用单品种请求能力，切回事实层遇到多个品种时，保留共享选择，暂停事实查询并提示“请选择一个品种查看事实”；用户明确选择一个品种或清空后再加载，避免只展示首个品种造成误解。**多品种事实查询属于已知接口缺口**，需后端确认扩展契约再补齐；不在前端拼接多个分页结果、猜测逗号参数或悄悄改变接口。

## 5. 查询职责

| 查询 | 输入 | 独立边界 |
| --- | --- | --- |
| 事实点/事实列表 | 现有 FactRequest | 沿用事实接口 |
| 关联图谱 | commodityIds、可选 factId/rootEntityId | 无日期、无地图相机；返回冷启动/上下文图谱 |
| 本体列表 | categories、commodityIds、q、page、pageSize | 不含地图范围；不从图谱节点派生 |
| 关联概览 | 无当前筛选 | 真实全局总数和今日新增；不得由图谱推算 |
| 本体/关系详情 | 唯一 ID | 独立请求，含完整证据和属性 |
| 处理日志 | SSE 连接 | 真实后台事件；不播放固定构建动画 |

普通分类和关系类型在已加载图谱上控制显隐；品种输入服务端，也在图谱显示时按 involved_varieties 校验。关闭关系类型不隐藏本体，但隐藏该类型的线及本体详情中的关系条目。右侧列表仅受分类、品种、名称查询影响。

图谱查询缓存键包括上下文 ID、品种和构建版本。切出切回同一上下文使用缓存；事实/起点/品种变化、手动刷新提高版本并重建。退出上下文回到默认图谱。无数据允许进入并展示空结果。

列表用独立无限分页查询；30 条一页，累计条数小于 total 时可加载下一页。所有分类关闭不发列表请求，直接显示空筛选结果。开启关联 API 后不会因 mode 切换自动重取列表，也不设置轮询。

## 6. 关联接口草案（参考事实层返回）

默认 `VITE_ENABLE_RELATION_API` 未配置或不是 `true` 时，不发送关联请求，不建立关联 SSE，显示“尚未接入”，统计用 `—`。事实请求和统一错误拦截保持原有方式。确认下表后在本地环境设置该开关。

| 路径（相对 VITE_API_BASE_URL） | 方法 | 请求 | 响应 |
| --- | --- | --- | --- |
| `/entities` | POST | `{ categories, commodityIds, q?, page, pageSize }` | `{ data: { items: Entity[], total } }` |
| `/entities/count` | GET | 无 | `{ data: { total, todayAdded, todayRelationsAdded } }` |
| `/graph/query` | POST | `{ commodityIds, factId?, rootEntityId? }` | `{ data: { entities, relations, focusEntityIds? } }` |
| `/entities/:id` | GET | 本体 ID | `{ data: Entity }` |
| `/relations/:id` | GET | 关系 ID | `{ data: Relation }` |
| `/relations/processing-logs/live` | SSE | 无 | 每条 data 为结构化处理事件 JSON |

列表由服务端按 updatedAt/createdAt 倒序；分类和品种取交集，多品种按任一命中；品种相关本体根据符合 involved_varieties 的关系两端和品种本体自身取得。列表与冷启动/上下文图谱不是同一集合。服务端需要提供缺坐标本体，不能只返回可上图对象。

Entity 保留项目既有 `id/name/type/position/factIds`，type 为二级分类，position 可空；追加字段为可选的 `address/regionPath/commodityIds/attributes/relationCount/relations/evidenceStatus/sourceType/evidence/createdAt/updatedAt`。Relation 保留 `id/sourceId/targetId/type/factIds`；追加 `involved_varieties/scopeLayer/evidenceStatus/sourceType/evidence/basis/attributes/source/target/createdAt/updatedAt`。字段名待后端核对，前端不引入转换后的视图模型。

- `regionPath`：参照事实 geo.regionPath 的 `{ code, name, level }[]`，用于国家/省级范围判断。
- `scopeLayer`：`global/china/hunan`，由后端依据两端地理范围维护；局部视角缺此字段时不推断普通线层级。
- `involved_varieties`：使用 PRD 指定字段名，值为现有品种 ID（例如 e:cmd:durian）；后端写入/更新/撤回支撑事实时维护。
- `sourceType`：仅 fact/preset。`evidenceStatus`：参照事实枚举 single_source/multi_source/pending/conflict。
- `evidence`：`{ factId, title, excerpt? }[]`，本体按事实写入时间倒序；关系逐条保留支撑事实和原文。无摘要时仍可通过 factIds 打开事实详情。
- `attributes`：本期以 PRD 展示字段名称为 key 的对象，不补写缺失字段。后端若改为受控字段 ID，先确认协议再调整查表。
- `source/target`：端点本体用于名称与分类展示；不会通过图谱中的少量节点冒充详情全部关系。
- 处理事件：`{ id, occurredAt, message, entityIds?, relationIds? }`；默认与上下文构建步骤均由后端在同一时间线发送。多个会话时需进一步确认上下文任务隔离/订阅参数，目前没有猜测任务 ID 或连接协议。
- 媒体字段现有事实 ApiFact 尚无统一结构，本期不伪造关联媒体字段；待共用媒体契约确认后补齐卡片和详情。

统计和日志保持真实口径，暂不从字符串日志解析数量或触发全局高频刷新。后台通知驱动统计更新和跨会话上下文日志订阅仍需确定事件契约。

## 7. 3D / 2D 渲染

`createRelationLayers` 独立于事实点、影响圈和叠加设施。节点同等像素半径、不使用分类图标；缺坐标留在列表和详情，重叠节点按最近写入/更新顺序优先拾取，不添加随机偏移。

曲线使用大圆路径采样和 PathLayer；3D 在路径上增加平滑高度，2D 用曲面路径投影，全球平面沿用项目 flattenWorldPosition。曲线、光点、方向箭头共用同一路径。六域颜色、三档支撑事实数线宽；合作无箭头且双向光点；其他类型单向。拾取只对业务节点和线启用，装饰光点、箭头不可拾取。

显隐按分类/品种 → 坐标与端点 → 地理层级/跨区域/重点 → 屏幕像素阈值处理。线的端点投影距离小于 8px 隐藏；两端都不可见的普通线不画。全球显示三级、国内显示中国/湖南、湖南显示湖南；跨区域线可越过层级限制。球体背面节点不参与可见端点判断。

选中本体高亮自身、一级邻居及直接关系，其他淡化；空白点击只取消高亮，不自动移动地图。日志中的真实写入 ID 亮起 3 秒，关闭或切换视角不移动地图。动画逐帧改变显示进度，不写入业务数量。

上线前还需真实数据验证：反经线和世界重复副本、球体地平线曲线遮挡、重叠节点拾取、8px 临界值与视觉方向、长距离曲线和浏览器 GPU 表现。当前不能以纯函数测试替代视觉验收。

## 8. 图谱后续实现技术方案

沿用现有 ECharts，不新增图引擎依赖。新增 `RelationGraphCanvas`，仅图谱模式挂载，覆盖在永久地图上方；被覆盖地图暂停旋转/交互。共用图谱查询和筛选结果，不取地图可见节点；含无坐标本体。图谱入口仅手动切换。

使用 graph series、force 布局、roam、受控缩放、固定节点大小；分类文字与六域颜色查表，节点/边 ID 保留原始本体/关系 ID。方向和合作规则同地图。点击节点使用相同 select 事件，点击边打开关系详情，一级邻居高亮通过相同邻接关系计算；空白清除高亮。右侧卡片与图谱缩放完全独立。

仅图谱内容发生变化时更新 nodes/links，选中和样式变化不重新运行整张力导向布局。切出保留已算节点位置、缩放和偏移；重新打开相同图谱恢复。按上下文构建版本重置布局，ResizeObserver 触发 resize，卸载 dispose。地图相机与图谱相机分别保存。

实现时先验证冷启动 20–30 节点与实际上下文图谱规模，检查中文标签碰撞、方向箭头、选择持续高亮与地图切换。未经需求确认不增加多跳展开、编辑节点、布局算法选择、数据库全量图谱或社区分析。

## 9. 验证与后续联调

前端检查：类型、lint、现有测试、构建；新增测试覆盖分层状态恢复、详情返回、关系字典与品种规则、无坐标、跨区域、像素阈值和合作方向。

后端实现后启用 API，联调独立列表与图谱、分页排序、缺失属性、完整证据、上下文重建、日志与统计同步、名称模糊查询。前端本地名称匹配只是已加载图谱的筛选，不能代替服务端 ES 搜索或承诺 P95 ≤ 300ms。
