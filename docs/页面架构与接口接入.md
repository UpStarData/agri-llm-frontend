# 页面架构与接口接入

2026-10-08 已按关联层 PRD V1.3 和本次确认更新。完整决策、待确认字段与图谱方案见 [关联层V1.3实现方案](./关联层V1.3实现方案.md)。

## 页面编排

事实层、关联层共用一个 Dashboard 和稳定挂载的 MapCanvas。左右面板共用 LayerDrawer；事实菜单/卡片与关联菜单/本体卡片分别组织业务。DetailDrawer 共用外壳，FactDetail、EntityDetail、RelationDetail 分别查询与展示。ProcessingLog 共用面板，按模式分别保存日志。

地图仅承担边界、相机、图层与交互。事实层显示事实点、影响范围及设施叠加，关联层显示同大小本体节点、有依据的关系曲线和方向效果。图谱本期不实现，技术方案见上述文档。

## 状态与数据

- 品种跨层同步；主题本地保存。
- 时间/事实分类/事实搜索属于事实层；关联分类/关系类型/关联搜索/跨区域属于关联层。
- 相机、视图、地域层级、选择、详情浏览栈、面板和列表位置按模式恢复。
- 关联查询不携带事实时间或地图相机；缩放/平移不刷新本体卡片列表。
- 本体列表与图谱独立请求，列表不从地图响应生成、不做 30 秒轮询。
- 关联总量独立查询，不由当前节点、关系线或分页条数推算。
- 支撑事实详情允许在关联 tab 内打开；后退回到原本体/关系。

## 接口接入

Axios 保持现有唯一实例与统一拦截。事实接口以 src/api/fact.ts 为准，返回 `{ data: ... }`；不改造为旧初始化文档中的裸 JSON。

关联后端尚未实现。src/api/relation.ts 参考事实返回建立契约草案，默认开关关闭；确认路径、字段和 SSE 格式后设置 `VITE_ENABLE_RELATION_API=true`。当前关联页面显示“尚未接入”，计数用 `—`，不注入随机或模拟业务数据。

早期 `/map/query`、`/stats/query` 和 `/graph/neighborhood` 的类型/接口是初始化预留，不是 PRD V1.3 已验证的后端契约。新页面不依赖旧 QueryContext 的 mode/地域/时间统一查询模型；它们暂保留给已有引用，后续确无使用时再清理。

详细端点、请求字段、两级分类、14 种关系、完整证据、媒体与多品种事实查询缺口均记录在 [关联层V1.3实现方案](./关联层V1.3实现方案.md)。
